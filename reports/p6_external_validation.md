## 4. Root Cause Analysis: Why Does Performance Drop?

### 1. Schema Truncation & Feature Incompatibility
P6 expects 56 bidirectional flow features generated by `CICFlowMeter`. UNSW-NB15 was generated using `Argus` and `Bro-IDS`, which do not compute TCP flag counts (`SYN Flag Count`, `RST Flag Count`, `FIN Flag Count`), packet size variances (`Packet Length Std`), or subflow active/idle dynamics. **40 out of 56 features (71.4%) are completely unobserved**, forcing tree paths through missing/zero branches.

### 2. Base-Rate Class Distribution Inversion
- **CIC-IDS2017:** 89.0% Benign, 11.0% Malicious.
- **UNSW-NB15:** 44.9% Benign, 55.1% Malicious.
This 5x shift in empirical prior probability invalidates uncalibrated posterior thresholds.

### 3. Attack Taxonomy Divergence
UNSW-NB15 includes attack classes such as `Generic` (synthetic crypto/checksum evasion), `Fuzzers`, `Analysis`, and `Exploits` targeting different OS environments, whereas CIC-IDS2017 focused on DoS/DDoS volumetric floods and Patator brute force.
