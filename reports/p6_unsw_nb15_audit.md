## 3. Data Hygiene: Missing Values, Duplicates & Types

- **Standard NaN / Null Count:** `0` across all columns in both training and testing partitions.
- **Missing Sentinel Value (`-`):** Column `service` contains `47,153` dash values (`57.27%` of test rows) indicating unassigned / non-standard application services.
- **Duplicate Flow Records (excluding `id`):**
  - Testing Set: `26,387` duplicated rows (`32.05%`)
  - Training Set: `67,601` duplicated rows (`38.55%`)
  *(These duplicate records are identical flow summaries generated by repeated network scanning and probing probes in the synthetic IXIA traffic generator).*
- **Feature Types:** 30 `int64`, 11 `float64`, 4 `object/str` (`proto`, `service`, `state`, `attack_cat`).

## 4. Forensic Identification & Potential Leakage Audit

| Category | Evaluated Fields | Audit Finding & Forensic Verification |
| :--- | :--- | :--- |
| **Row Identifiers** | `id` | Sequential index (1..82,332). Must be stripped prior to inference to prevent positional bias. |
| **Direct Network IPs** | `srcip`, `dstip` | Present in raw CSVs (`UNSW-NB15_1..4.csv`), but stripped from official benchmark sets (`UNSW_NB15_testing-set.csv`). |
| **Port Numbers** | `sport`, `dsport` | Present in raw CSVs, but omitted from benchmark sets. |
| **Timestamps** | `Stime`, `Ltime` | Omitted from benchmark sets; prevents direct epoch memorization. |
| **OS Stack Fingerprints** | `sttl`, `dttl`, `swin`, `dwin` | **POTENTIAL LEAKAGE:** TTL and TCP window size values strongly correlate with synthetic attacker VMs vs victim hosts. |
| **Window Aggregations** | `ct_srv_src`, `ct_dst_ltm`, etc. | 10 dataset-specific connection count metrics over 100-connection sliding windows. Unique to UNSW-NB15 methodology. |
